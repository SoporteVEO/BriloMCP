brilo-sqlserver-mcp

Read-only Model Context Protocol server for the Brilo ERP SQL Server database. This is an API endpoint — there is no UI here.

Endpoints

  • GET /health — public health check (no auth).
  • POST /mcp — MCP Streamable HTTP endpoint. Requires Authorization: Bearer <MCP_AUTH_TOKEN>.

Quick check

curl https://<this-host>/health
curl -X POST https://<this-host>/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Authorization: Bearer $MCP_AUTH_TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"curl","version":"0"}}}'
